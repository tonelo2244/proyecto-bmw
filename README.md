
# Proyecto BMW — Tu Garaje BMW

Proyecto web desarrollado como práctica de HTML5 y CSS3 durante el primer año de mi formación en desarrollo web.

La página muestra varios modelos de motocicletas BMW mediante un diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

- HTML5 para la estructura de la página.
- CSS3 para los estilos.
- Flexbox y CSS Grid para organizar los elementos.
- Media queries para adaptar el diseño a móviles y tablets.

## Qué he trabajado

- Estructura semántica con HTML.
- Menú de navegación y enlaces internos.
- Secciones con imágenes y tarjetas.
- Formulario de contacto a nivel visual, sin backend.
- Diseño responsive.

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir el archivo `index.html` en un navegador.

## Estado del proyecto

Proyecto académico de aprendizaje. El formulario de contacto es demostrativo y no envía mensajes.
